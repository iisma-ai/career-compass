## E10 run and results
- **What:** `uv run python -I -X utf8 research/feasibility/e10_gap_mitigation.py` (smoke run first; no changes after
  the pre-registration commit).
- **Outcome: not viable.** Gap .042 at 24 items. The best rule, C3 (extend to 40 when differentiation < 1.5, mean
  26.9 items), gives .030; 40 for all gives .040. C3 raises both groups' agreement. Teens: .070 → .054.
- **Post-hoc (exploratory, `research/feasibility/e10_posthoc.py`):** a 40-item reference changes the gap only to .037.
  Reweighting men to women's profile-shape mix (top-2 code × differentiation) gives .011 (teens .023). Most of the gap
  is answer composition.
- **Decision (ADR 0022):** no form change now. The raw vs answer-conditional 1.6(a) bar is the owner's decision
  (answer-conditional recommended). C3 needs a live test before adoption.
- **Files:** E10 findings, `.json`, `.png`, `e10_posthoc.py`/`.json`; ADR 0022; ROADMAP 1.6; RESEARCH §5; STATUS; README; CLAUDE.md.
